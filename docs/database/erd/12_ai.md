# 12 AI Assistants

Owns assistants, conversations, messages, tools, tool calls, approval requests, context snapshots, prompts, recommendations, and usage records.

External dependencies: `organizations`, `profiles`, business target records.

```mermaid
erDiagram
    ai_assistants {
        uuid id PK
        text assistant_type
    }
    ai_conversations {
        uuid id PK
        uuid assistant_id FK
        uuid organization_id FK
        uuid user_id FK
    }
    ai_messages {
        uuid id PK
        uuid conversation_id FK
        text role
    }
    ai_tools {
        uuid id PK
        text tool_name
    }
    ai_tool_calls {
        uuid id PK
        uuid conversation_id FK
        uuid tool_id FK
        text status
    }
    ai_action_requests {
        uuid id PK
        uuid tool_call_id FK
        text status
    }
    ai_context_snapshots {
        uuid id PK
        uuid conversation_id FK
    }
    ai_prompts {
        uuid id PK
        text prompt_key
    }
    ai_usage_records {
        uuid id PK
        uuid conversation_id FK
        numeric cost
    }
    ai_recommendations {
        uuid id PK
        uuid organization_id FK
        uuid user_id FK
        text target_type
    }

    ai_assistants ||--o{ ai_conversations : conversations
    ai_conversations ||--o{ ai_messages : messages
    ai_conversations ||--o{ ai_tool_calls : tool_calls
    ai_tools ||--o{ ai_tool_calls : executes
    ai_tool_calls ||--o{ ai_action_requests : approvals
    ai_conversations ||--o{ ai_context_snapshots : context
    ai_conversations ||--o{ ai_usage_records : usage
```

AI output must remain advisory; authorization and high-risk action approval stay server-side.
